# NTQQ_Response v1.0.0 发布说明

针对新版 Windows **NTQQ (9.9.x)** 打造的 Windows 11 原生系统级 Toast 通知快捷回复助手。

无需点开或切出 QQ 主界面，直接在屏幕右下角通知横幅内打字即可秒回好友与群消息，工作、游戏与全屏观影时沟通快人一步！

---

## 🌟 核心功能亮点

### 1. 💬 Windows 11 原生通知内联秒回
- 基于 WinRT 原生 `ToastNotification` 与 COM `INotificationActivationCallback` 后台激活技术。
- 直接在横幅输入框内打字，敲击回车或点击“发送”即通过 NTQQ 内核发送，**不抢占窗口焦点、不拉起 QQ 主界面**。

### 2. 📜 打字中来新消息“原位无损追加”
- **绝不打断思路**：当同一好友或群聊连续发来多条消息时，采用系统通知数据绑定（`ToastNotifier.Update`），在正在输入的文本框正上方平滑滚动追加最新消息内容，**绝不会清空或覆盖您正在输入的文字**。

### 3. 🔔 多联系人消息无缝调度与角标提醒
- 当您正在给好友 A 打字时，若好友 B 或群聊 C 发来新消息，横幅顶部会优雅浮现一行实时提醒（如 `🔔 刚刚 [某某] 发来新消息`）。
- 当前消息发送或横幅关闭后，队列中的下一位联系人消息会自动无缝接替弹出。

### 4. 🔕 严格尊重新版 QQ 消息免打扰分类
- 深度适配 NTQQ 内核中的 `GroupService` 与 `RecentContactService` 屏蔽规则。
- 设置为“接收消息但不提醒”、“收进群助手”的免打扰群聊平时保持完全静默；**仅在有人 `@我`、`@全体成员` 或直接引用回复我的消息时**，才触发高优先级横幅通知并自动标注 `[有人@我]`。

### 5. 🚫 智能屏蔽 QQ 原生重复弹窗
- 内置 Electron 通知拦截与系统通知层注册表静默逻辑，避免原版 QQ 弹窗与 Windows 11 快捷回复横幅同时出现的“双响”现象；退出或卸载时自动完整恢复。

### 6. 🛡️ 零文件破坏与免维护
- 不篡改 `application.asar`、`package.json` 或 `QQNT.dll` 等任何官方核心文件，完美通过 NTQQ 官方 `application.json` RSA-2048 完整性签名校验。

### 7. 🪶 纯托盘静默驻留
- 采用类 TranslucentTB 的纯托盘化常驻架构，无任何常驻多余窗口，内存占用仅 10MB~20MB，几乎为 0% CPU 占用。
- 支持开机自启动、QQ 主窗口位于前台时智能静默等实用选项。

## 📦 下载与安装指南

### 方式一：推荐使用单文件安装向导（一键安装）
1. 下载 **`NTQQ_Response_Setup_v1.0.0.exe`**。
2. 双击运行，安装器会自动扫描并识别您本机的 NTQQ 安装路径（默认通常为 `C:\Program Files\Tencent\QQNT`）。
3. 点击 **“一键安装并启动”**，程序会自动部署桥接补丁并拉起托盘助手，即可立即体验！

### 方式二：使用便携包（手动部署）
1. 下载 **`NTQQ_Response_Portable_v1.0.0.zip`** 并解压。
2. 将 `version.dll` 放置于 QQ 安装主目录下（即 `QQ.exe` 同级目录）。
3. 在 `QQNT\resources` 下创建 `qqtoast.js`（可由安装向导生成或解压包中的 `qq-bridge.js` 复制并重命名）。
4. 运行 `QQToastTray.exe` 启动系统托盘通知服务。

## 🗑️ 卸载与还原

如需恢复 QQ 原版行为，无需担心任何系统或 QQ 损坏：
- **一键卸载**：再次打开 `NTQQ_Response_Setup_v1.0.0.exe`，点击 **“彻底卸载恢复原版”**；
- 或者直接右键屏幕右下角的蓝色 QQToast 托盘图标，选择 **“卸载 QQ 桥接组件”** 即可，所有原版配置与通知无损恢复。

- **操作系统**：Windows 11（推荐）或 Windows 10 (1809 及以上版本)
