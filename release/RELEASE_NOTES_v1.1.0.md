# NTQQ_Response v1.1.0 发布说明与更新日志

NTQQ_Response v1.1.0 是针对新版 Windows **NTQQ (9.9.x)** 打造的 Windows 11 原生快捷回复助手的重大体验升级版本！

在保留 v1.0.0 “原生通知内打字秒回”、“打字中实时无损追加新消息”、“严格遵循 QQ 免打扰分类”、“自动屏蔽原生重复弹窗”等强大能力的基础上，v1.1.0 重点带来了 **4 项重磅功能升级**：

---

## 🚀 v1.1.0 更新日志 (Changelog)

### 1. 🔝 优化消息堆叠与超长文本截断逻辑（永远以最新消息为主）+ 托盘上限自定义
- **最新消息绝对优先**：Windows Toast 通知卡片可视高度有限（约 4 行），旧消息过长易将最新一条消息挤出视野。v1.1.0 引入全新倒推排版算法：
  - 自动清洗单条消息中的多余换行符（替换为空格），防止换行霸屏；
  - 非最新历史消息单条最多保留 26 字（超出自动折叠为 `...`）；
  - 最底部的最新消息保障完整展示（支持最多保留 50~80 字），并加入所有展示消息 `<= 110` 字的总字数硬上限保护，确保**最新消息永远不会被旧消息挤出卡片可视区域**！
- **托盘菜单直接调节**：
  - 右键托盘图标新增二级菜单 **“消息堆叠与字数上限”**；
  - 支持快捷选择保留条数：`最多堆叠 1 条 (仅最新)`、`最多堆叠 2 条`、`最多堆叠 3 条 (默认)`、`最多堆叠 4 条`；
  - 支持快捷选择单条字数上限：`单条上限 30 字 (紧凑)`、`单条上限 50 字 (默认)`、`单条上限 80 字 (宽松)`。

### 2. 🖼️ 收到图片时在通知卡片中显示缩略图（Inline Image）
- **图文并茂一目了然**：当好友或群聊发送图片时，内核桥接自动提取并解析 NTQQ 本地缩略图缓存（如遇新图未落盘则通过 `downloadRichMedia` 极速调度落盘）；
- **WinRT 原生内联渲染**：在通知卡片正文中以 `<image placement="inline" />` 优雅展示图片缩略图，在通知栏即可看清图片，无需打开 QQ 主窗口！
- **焦点无损热更新**：当从纯文字变为图片时，平滑升级卡片横幅；在用户正在打字时，后续文本消息仍保持原位追加，绝不清空文字。

### 3. 🖱️ 点击通知卡片直接打开 QQ 主窗口并跳转到对应会话
- **一键直达聊天**：当您需要查看长图、发送文件或使用完整聊天功能时，只需直接点击通知卡片主体任意空白区域；
- **智能置顶与定位**：托盘助手与 Electron 桥接联动，自动还原并聚焦 QQ 主窗口至屏幕最前端，并通过 NTQQ `RecentContactService.jumpToSpecifyRecentContact` API 自动将当前聊天视窗切换至该好友或群聊，省去从漫长会话列表中手动翻找的繁琐步骤！

### 4. ⚡ 支持“跟随 QQ 打开而自动启动托盘助手”
- **免除手动双开**：托盘右键菜单新增 **“跟随 QQ 启动自动运行”** 开关（默认勾选）；
- **内核级保活联动**：当 QQ 启动后，内核桥接检测到托盘助手未运行时，会自动在后台静默拉起 `QQToastTray.exe`，无需设置复杂的系统计划任务或开机启动项，开 QQ 即享快捷回复！

## 📦 下载与安装指南

### 方式一：推荐使用单文件安装向导（一键安装）
1. 下载 **`NTQQ_Response_Setup_v1.1.0.exe`**。
2. 双击运行，向导会自动识别本机的 NTQQ 安装路径。
3. 点击 **“一键安装并启动”** 即可完成全部部署与即刻体验。

### 方式二：使用便携包（手动部署）
1. 下载 **`NTQQ_Response_Portable_v1.1.0.zip`** 并解压。
2. 将 `version.dll` 放置于 QQ 安装主目录下（即 `QQ.exe` 同级目录）。
3. 运行 `QQToastTray.exe` 启动系统托盘通知服务。

---

## 🗑️ 卸载与还原

- 双击运行 `NTQQ_Response_Setup_v1.1.0.exe`，点击 **“彻底卸载恢复原版”**；
- 或直接右键托盘图标选择 **“卸载 QQ 桥接组件”** 即可，所有原版设置与系统通知完整复原。
